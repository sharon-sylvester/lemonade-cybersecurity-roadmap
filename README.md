## Project Overview

This cybersecurity roadmap was developed as a team project for a digital insurance company. The project focused on creating a structured approach to strengthening the organization's security posture while supporting business continuity, regulatory compliance, and customer trust.

## Key Areas

- Security gap analysis and risk identification
- Cybersecurity roadmap development
- SOC expansion and staffing considerations
- Security awareness and employee training
- Governance, Risk, and Compliance (GRC)
- Security controls including SIEM, EDR, IDS/IPS, firewalls, and MFA
- Network segmentation and role-based access control
- Cloud migration considerations
- Continuous monitoring and improvement
- Resource allocation and budget considerations
